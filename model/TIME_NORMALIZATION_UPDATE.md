# 时间归一化功能更新说明

## 概述

此更新实现了基于线性插值的时间归一化功能，解决了原有简单截断/填充方法的不足。新功能能够将不同长度的时间序列数据（传感器数据）统一归一化到固定长度，同时保持数据的趋势和连续性。

## 更新内容

### 1. 新增 time_normalization.py 模块

实现了以下功能：
- `time_normalize_sequence(sequence, target_length)`: 对单个时间序列进行线性插值归一化
- `time_normalize_batch(sequences, target_length)`: 批量处理多个时间序列

### 2. 更新 training.py

- 添加了对 time_normalization 模块的导入
- 将原来简单的截断/填充逻辑替换为线性插值归一化
- 注释明确说明了使用线性插值进行时间归一化

### 3. 更新 test_model.py

- 添加了对 time_normalization 模块的导入
- 将预处理函数中的截断/填充逻辑替换为线性插值归一化
- 保持了与训练阶段一致的数据处理方式

## 技术细节

### 线性插值算法

对于输入序列长度为 N，目标长度为 M 的时间归一化：
- 当 N > M 时：压缩序列，使用线性插值选择代表性数据点
- 当 N < M 时：扩展序列，使用线性插值填充缺失数据点
- 当 N = M 时：直接返回原序列

### 支持的场景

- 任意长度的时间序列数据
- 传感器数据（如加速度计、陀螺仪数据）
- 保持原始数据的趋势和关键特征
- 处理极短序列（如单个数据点）和空序列的边界情况

## 优势

相比原来的截断/填充方法，新方法具有以下优势：
1. 保持数据的连续性和趋势
2. 更好地保留原始动作的特征
3. 避免因简单填充零值而引入噪声
4. 提高模型对不同执行速度动作的识别准确性

## 验证

通过 comprehensive_test.py 进行了全面验证：
- 不同长度输入的处理能力
- 模块导入和集成测试
- 数据连续性验证
- 边界情况处理
- 与现有系统的兼容性
