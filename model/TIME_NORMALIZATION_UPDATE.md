# 项目更新说明

## 概述

此更新包含两个主要改进：
1. 实现了基于线性插值的时间归一化功能，解决了原有简单截断/填充方法的不足
2. 在神经网络模型中添加了Dropout层，提高了模型的泛化能力

新功能能够将不同长度的时间序列数据（传感器数据）统一归一化到固定长度，同时保持数据的趋势和连续性，并通过Dropout层减少过拟合。

## 更新内容

### 1. 新增 time_normalization.py 模块

实现了以下功能：
- `time_normalize_sequence(sequence, target_length)`: 对单个时间序列进行线性插值归一化
- `time_normalize_batch(sequences, target_length)`: 批量处理多个时间序列

### 2. 更新 training.py - 时间归一化部分

- 添加了对 time_normalization 模块的导入
- 将原来简单的截断/填充逻辑替换为线性插值归一化
- 注释明确说明了使用线性插值进行时间归一化

### 3. 更新 test_model.py - 时间归一化部分

- 添加了对 time_normalization 模块的导入
- 将预处理函数中的截断/填充逻辑替换为线性插值归一化
- 保持了与训练阶段一致的数据处理方式

### 4. 更新 training.py - 添加Dropout层

- 在Conv1D层和Dense层后添加了Dropout(0.3)层
- 有助于防止模型过拟合，提高泛化能力
- 在卷积层和全连接层后都添加了dropout以增强正则化效果

### 5. 新增数据可视化对比功能

- 在visualize_gyro_data.py中新增compare_original_and_normalized函数
- 提供原始数据和归一化数据的可视化对比
- 包含加速度计和陀螺仪数据的对比图表
- 显示统计信息对比（均值和标准差）
- 支持中英文版本以适应不同环境

## 技术细节

### 线性插值算法

对于输入序列长度为 N，目标长度为 M 的时间归一化：
- 当 N > M 时：压缩序列，使用线性插值选择代表性数据点
- 当 N < M 时：扩展序列，使用线性插值填充缺失数据点
- 当 N = M 时：直接返回原序列

### Dropout正则化

在模型中添加了Dropout(0.3)层：
- 在卷积层之后添加Dropout层，丢弃30%的神经元
- 在全连接层之后也添加Dropout层，进一步正则化
- 有助于减少过拟合，提高模型的泛化能力

### 数据可视化对比

新增了可视化对比功能：
- 可以同时显示原始数据和归一化后的数据
- 提供加速度计和陀螺仪数据的对比图表
- 生成统计信息对比，便于分析算法效果
- 支持中英文界面，适应不同环境

### 支持的场景

- 任意长度的时间序列数据
- 传感器数据（如加速度计、陀螺仪数据）
- 保持原始数据的趋势和关键特征
- 处理极短序列（如单个数据点）和空序列的边界情况

## 优势

相比原来的截断/填充方法和之前的模型架构，更新后的系统具有以下优势：
1. 保持数据的连续性和趋势（时间归一化）
2. 更好地保留原始动作的特征（时间归一化）
3. 避免因简单填充零值而引入噪声（时间归一化）
4. 提高模型对不同执行速度动作的识别准确性（时间归一化）
5. 通过Dropout层减少过拟合，提高模型泛化能力
6. 在保持性能的同时增强模型的鲁棒性
7. 提供可视化对比功能，便于分析时间归一化效果
